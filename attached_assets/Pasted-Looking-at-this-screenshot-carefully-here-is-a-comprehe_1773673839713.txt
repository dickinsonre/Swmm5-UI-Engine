## Improvement 1 — Map Canvas: Empty Space Problem

The biggest UX issue. The network occupies roughly 30% of the canvas. The remaining 70% is blank gray. Three fixes:

**Auto fit-to-extent on load:**
```ts
// On file load or first render, auto-zoom to network bounds
function fitNetworkToCanvas(nodes: Node[], canvas: HTMLCanvasElement) {
  const xs = nodes.map(n => n.x);
  const ys = nodes.map(n => n.y);
  const padding = 80; // px

  const minX = Math.min(...xs) - padding;
  const maxX = Math.max(...xs) + padding;
  const minY = Math.min(...ys) - padding;
  const maxY = Math.max(...ys) + padding;

  const scaleX = canvas.width  / (maxX - minX);
  const scaleY = canvas.height / (maxY - minY);
  const zoom   = Math.min(scaleX, scaleY);

  return {
    zoom,
    panX: -minX * zoom,
    panY: -minY * zoom,
  };
}
```

**Add a subtle grid** to the empty canvas so it reads as a work surface, not empty space:

```css
.map-canvas {
  background-color: #f8f9fb;
  background-image:
    linear-gradient(rgba(180,195,215,0.4) 1px, transparent 1px),
    linear-gradient(90deg, rgba(180,195,215,0.4) 1px, transparent 1px),
    linear-gradient(rgba(180,195,215,0.15) 1px, transparent 1px),
    linear-gradient(90deg, rgba(180,195,215,0.15) 1px, transparent 1px);
  background-size: 100px 100px, 100px 100px, 20px 20px, 20px 20px;
}
```

**Replace the hint text** at the bottom of the canvas. The current "Click Project > Run to simulate, or drag an .inp file here" is fine as text but competes with nothing. Make it a proper empty state:

## Improvement 2 — Left Panel: Legend + Layers Merger

The left panel has two separate sections — **Map Legend** and **Layers** — that are logically one thing. Merge them into a single **Legend & Layers** panel where each legend row has its own visibility toggle:

```tsx
// Before: separate Legend section + separate Layers checkboxes
// After: unified rows

function LegendRow({ color, label, visible, onToggle }) {
  return (
    <label className="flex items-center gap-2 cursor-pointer
                      hover:bg-slate-100 px-2 py-1 rounded group">
      <input
        type="checkbox"
        checked={visible}
        onChange={onToggle}
        className="accent-blue-500"
      />
      <span
        className="w-4 h-3 rounded-sm border border-slate-300 shrink-0"
        style={{ background: color }}
      />
      <span className="text-xs text-slate-600 flex-1">{label}</span>
    </label>
  );
}
```

This removes 40% of the left panel height and eliminates the disconnect between "what the colors mean" and "whether to show them."

## Improvement 5 — Node Rendering on Canvas

The current nodes are plain filled circles with no depth or state differentiation. After simulation, they should communicate hydraulic state visually:

```ts
function drawNode(ctx, node, results, theme) {
  const depth = results?.nodeDepth[node.id] ?? 0;
  const maxDepth = node.maxDepth || 4;
  const fillRatio = Math.min(depth / maxDepth, 1);

  // Outer ring — always node type color
  ctx.beginPath();
  ctx.arc(node.sx, node.sy, NODE_RADIUS + 3, 0, Math.PI * 2);
  ctx.fillStyle = nodeTypeColor(node.type);
  ctx.fill();

  // Inner fill — depth as water level (blue fill rising from bottom)
  ctx.beginPath();
  ctx.arc(node.sx, node.sy, NODE_RADIUS, 0, Math.PI * 2);
  ctx.fillStyle = "#ffffff";
  ctx.fill();

  // Water level arc
  if (fillRatio > 0) {
    const startAngle = Math.PI - (fillRatio * Math.PI);
    ctx.beginPath();
    ctx.arc(node.sx, node.sy, NODE_RADIUS, startAngle, Math.PI * 2 - startAngle);
    ctx.fillStyle = depthColor(fillRatio); // blue → yellow → red
    ctx.fill();
  }

  // Flooding indicator — pulsing red halo
  if (depth >= maxDepth) {
    ctx.beginPath();
    ctx.arc(node.sx, node.sy, NODE_RADIUS + 6, 0, Math.PI * 2);
    ctx.strokeStyle = "#ef4444";
    ctx.lineWidth = 2;
    ctx.setLineDash([3, 3]);
    ctx.stroke();
    ctx.setLineDash([]);
  }
}
```

After running a simulation, the current UI has no way to animate through timesteps. Add a time slider that appears in the toolbar when results are loaded:

```tsx
{results && (
```
