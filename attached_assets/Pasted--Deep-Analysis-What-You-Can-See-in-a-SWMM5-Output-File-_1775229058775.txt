## The Three Tiers of SWMM5 Output Data

### Tier 1: Standard EPA Binary .out File (What most users see)

### Tier 2: Extended Output (RED/Innovyze Build)

Your enum list reveals that the Innovyze RED build expanded`MAX_NODE_RESULTS`,`MAX_LINK_RESULTS`, and`MAX_SUBCATCH_RESULTS` to **100 slots each**, exposing solver internals that EPA SWMM never writes to the .out file. These are the variables that reveal **how the engine actually works**:

#### Node Solver Internals (Tier 2)

```
What the Newton-Raphson solver computes at EVERY node, EVERY iteration:

NODE_DQDH (idx 15)     — The Jacobian: ∂Q/∂H
  └→ This is the SENSITIVITY of total flow to head change
  └→ Feeds directly into the NR update: ΔH = -F/denom
  └→ When dQ/dH → 0, the system is STIFF and convergence fails

NODE_F (idx 17)         — The RESIDUAL: F(H) = ΣQ_in - ΣQ_out - dV/dt
  └→ When F(H) = 0, continuity is satisfied
  └→ The solver iterates to make this zero
  └→ Non-zero at end of iterations = unconverged

NODE_CORRECTION (idx 20) — ΔH = -F(H) / denominator
  └→ The actual HEAD CHANGE applied each iteration
  └→ max|ΔH| < HEAD_TOLERANCE = convergence achieved
  └→ Tracking this shows WHERE convergence is slowest

NODE_DENOM (idx 16)     — dQ/dH + SurfArea/Δt
  └→ The denominator in Newton-Raphson
  └→ When → 0, the solver DIVIDES BY ZERO → instability
  └→ SurfArea/Δt term is the STABILIZER

NODE_ITERATIONS (idx 21) — How many NR iterations this step
  └→ 2-3 = healthy system
  └→ = MAX_TRIALS (8 default) = DID NOT CONVERGE
  └→ This is the #1 diagnostic for model problems

NODE_CONVERGENCE (idx 23) — Binary: converged (1) or not (0)
  └→ Map this at each timestep to see WHERE trouble is

NODE_CE (idx 14)        — Per-node continuity error
  └→ Unlike the .rpt summary, this is PER NODE PER STEP
  └→ Shows exactly which nodes are losing/gaining mass
```

#### Link Momentum Equation Terms (Tier 2 — THE inner workings)

This is where your code really shines. The **six DQ terms** are the actual terms in the St. Venant momentum equation:

```
The FULL finite-difference momentum equation:

Q_new = [DQ1 + DQ2 + DQ5] / [1 + DQ3_denom + DQ4_denom + DQ6_denom]

Where:

DQ1 (idx 10) — INERTIA: σ · Q_old
  └→ σ = inertial damping factor (0 to 1)
  └→ σ = 1: full inertia (free surface flow)
  └→ σ → 0: inertia removed (surcharged/pressure flow)
  └→ This is HOW SWMM transitions from open channel to pipe flow
  └→ INERTIAL_DAMPING option controls the σ curve

DQ2 (idx 11) — PRESSURE GRADIENT: σ · Δt · g · Ā · (H₁-H₂) / L
  └→ THE DRIVING FORCE of flow
  └→ Head difference / pipe length = hydraulic gradient
  └→ × gravity × area × timestep
  └→ This is the term that MOVES WATER through the system
  └→ When H₁ > H₂: positive flow (downstream)
  └→ When H₁ < H₂: REVERSE FLOW (backwater)

DQ3 (idx 12) — FRICTION: Δt · g · Ā · Sf
  └→ Manning friction: Sf = (n·|Q| / (κ·A·R^⅔))²
  └→ Always OPPOSES flow direction
  └→ This is where Manning's n has its effect
  └→ THE dominant loss in most pipes
  └→ κ = 1.49 (US) or 1.0 (SI)

DQ4 (idx 13) — MINOR LOSSES: K_entry·V²/2g + K_exit·V²/2g + K_avg·V²/2g
  └→ From [LOSSES] section
  └→ Entry losses at pipe inlet
  └→ Exit losses at pipe outlet
  └→ Average losses along pipe (bends, fittings)

DQ5 (idx 14) — LATERAL MOMENTUM: from side inflows
  └→ When subcatchment runoff enters a node, it carries momentum
  └→ Usually small compared to DQ2 and DQ3
  └→ But can matter at nodes with large lateral inflow

DQ6 (idx 15) — CONVECTIVE ACCELERATION: σ · ∂(βQ²/A)/∂x
  └→ Spatial change in momentum flux
  └→ Important at expansions/contractions
  └→ Can DESTABILIZE the solver
  └→ Set to 0 when INERTIAL_DAMPING = FULL (diffusion wave)
  └→ The "noisy" term that causes oscillations
```

#### Link Energy / Bernoulli Balance (Tier 2)

```
The Bernoulli energy equation check — does energy balance?

LINK_BE_LHS (idx 61) — Left side:  H₁ + V₁²/(2g) + K_entry·V₁²/(2g)
LINK_BE_RHS (idx 62) — Right side: H₂ + V₂²/(2g) + K_exit·V₂²/(2g) + h_f

If LHS ≈ RHS: energy is conserved (good!)
If LHS ≠ RHS: energy balance error → numerical issues

Components:
  LINK_VHUP  (idx 57) — V₁²/(2g)  upstream velocity head
  LINK_VHMID (idx 58) — V_mid²/(2g) midpoint velocity head
  LINK_VHDN  (idx 59) — V₂²/(2g)  downstream velocity head
  LINK_VHHF  (idx 60) — Sf × L    friction head loss

LINK_SIGMA (idx 64) — σ inertial damping factor (0 to 1)
  └→ THE transition control between open channel and pressure flow
  └→ σ = 1: free surface (momentum equation uses all terms)
  └→ σ = 0: fully surcharged (reduces to diffusion equation)
  └→ Transition zone is where instability lives
```

#### Link Geometry at Both Ends (Tier 2)

```
Cross-section properties computed at BOTH ends of every pipe:

LINK_A1, LINK_A2     — Flow area upstream/downstream
LINK_R1, LINK_R2     — Hydraulic radius upstream/downstream
LINK_W1, LINK_W2     — Top width upstream/downstream
LINK_Y1, LINK_Y2     — Water depth upstream/downstream
LINK_V1, LINK_V2     — Velocity upstream/downstream
LINK_F1, LINK_F2     — Area function for momentum equation

LINK_AMID            — Midpoint area = (A1+A2)/2
LINK_RMID            — Midpoint hydraulic radius

Why this matters:
  - A1 ≠ A2 means non-uniform flow (gradually/rapidly varied)
  - V1 >> V2 means flow is decelerating (energy converting to pressure)
  - V1 << V2 means flow is accelerating (pressure converting to velocity)
  - When A1 → 0 or A2 → 0, the pipe is partially dry → instability risk
```

### Phase B: Diagnostic Overlay on Existing Results (8-12 hours)

Use the standard .out data to COMPUTE derived diagnostics:

```javascript
class SWMMDiagnostics {
  constructor(results, model) {
    this.results = results;
    this.model = model;
  }

  // Compute Froude number from standard output
  getFroude(linkId, timestep) {
    const flow = this.results.getLinkResult(linkId, 'flow', timestep);
    const depth = this.results.getLinkResult(linkId, 'depth', timestep);
    const cond = this.model.conduits.get(linkId);
    if (!cond || depth <= 0) return 0;
    
    const area = this.getArea(cond.xsecShape, cond.xsecGeom1, depth);
    const topWidth = this.getTopWidth(cond.xsecShape, cond.xsecGeom1, depth);
    const velocity = flow / area;
    const celerity = Math.sqrt(32.174 * area / topWidth);
    return Math.abs(velocity) / celerity;
  }

  // Compute pipe slope from node elevations
  getSlope(linkId) {
    const cond = this.model.conduits.get(linkId);
    if (!cond) return 0;
    const fromNode = this.model.getObject('junction', cond.fromNode) || 
                     this.model.getObject('storage', cond.fromNode);
    const toNode = this.model.getObject('junction', cond.toNode) ||
                   this.model.getObject('outfall', cond.toNode);
    if (!fromNode || !toNode || !cond.length) return 0;
    return (fromNode.invertElev + (cond.inletOffset || 0) - 
            toNode.invertElev - (cond.outletOffset || 0)) / cond.length;
  }

  // Compute normal flow capacity
  getQnormal(linkId) {
    const cond = this.model.conduits.get(linkId);
    if (!cond) return 0;
    const slope = Math.abs(this.getSlope(linkId));
    const n = cond.roughness || 0.013;
    const aFull = this.getFullArea(cond.xsecShape, cond.xsecGeom1, cond.xsecGeom2);
    const rFull = this.getFullHydRadius(cond.xsecShape, cond.xsecGeom1, cond.xsecGeom2);
    return (1.49 / n) * aFull * Math.pow(rFull, 2/3) * Math.sqrt(slope);
  }

  // Estimate friction slope from Manning's equation
  getFrictionSlope(linkId, timestep) {
    const flow = Math.abs(this.results.getLinkResult(linkId, 'flow', timestep));
    const depth = this.results.getLinkResult(linkId, 'depth', timestep);
    const cond = this.model.conduits.get(linkId);
    if (!cond || depth <= 0) return 0;
    
    const area = this.getArea(cond.xsecShape, cond.xsecGeom1, depth);
    const hydRadius = this.getHydRadius(cond.xsecShape, cond.xsecGeom1, depth);
    const n = cond.roughness || 0.013;
    
    // Sf = (n*Q / (1.49*A*R^(2/3)))^2
    const denom = 1.49 * area * Math.pow(hydRadius, 2/3);
    if (denom === 0) return 0;
    return Math.pow(n * flow / denom, 2);
  }

  // Estimate head loss per pipe
  getHeadLoss(linkId, timestep) {
    const sf = this.getFrictionSlope(linkId, timestep);
    const cond = this.model.conduits.get(linkId);
    return sf * (cond?.length || 0);
  }

  // Flow classification
  getFlowClass(linkId, timestep) {
    const depth = this.results.getLinkResult(linkId, 'depth', timestep);
    const cond = this.model.conduits.get(linkId);
    if (!cond) return 'UNKNOWN';
    
    if (depth <= 0.001) return 'DRY';
    if (depth >= cond.xsecGeom1 * 0.97) return 'FULL';
    
    const fr = this.getFroude(linkId, timestep);
    if (fr < 0.01) return 'STAGNANT';
    if (fr < 1.0) return 'SUBCRITICAL';
    if (fr > 1.0) return 'SUPERCRITICAL';
    return 'CRITICAL';
  }

  // Energy grade line
  getEGL(linkId, timestep) {
    const flow = this.results.getLinkResult(linkId, 'flow', timestep);
    const depth = this.results.getLinkResult(linkId, 'depth', timestep);
    const cond = this.model.conduits.get(linkId);
    if (!cond || depth <= 0) return { up: 0, dn: 0 };

    const fromNode = this.model.getObject('junction', cond.fromNode) ||
                     this.model.getObject('storage', cond.fromNode);
    const toNode = this.model.getObject('junction', cond.toNode) ||
                   this.model.getObject('outfall', cond.toNode);
    
    const h1 = this.results.getNodeResult(cond.fromNode, 'head', timestep);
    const h2 = this.results.getNodeResult(cond.toNode, 'head', timestep);
    
    const area = this.getArea(cond.xsecShape, cond.xsecGeom1, depth);
    const v = area > 0 ? flow / area : 0;
    const vh = v * v / (2 * 32.174);
    
    return {
      hglUp: h1,
      hglDn: h2,
      eglUp: h1 + vh,
      eglDn: h2 + vh,
      velocityHead: vh,
      frictionLoss: this.getHeadLoss(linkId, timestep),
    };
  }

  // Cross-section geometry functions
  getArea(shape, geom1, depth) {
    const d = Math.max(0, Math.min(depth, geom1));
    switch (shape?.toUpperCase()) {
      case 'CIRCULAR': {
        const D = geom1;
        const r = D / 2;
        const theta = 2 * Math.acos(1 - d / r);
        return r * r / 2 * (theta - Math.sin(theta));
      }
      case 'RECT_CLOSED':
      case 'RECT_OPEN':
        return d * (geom1 || d); // width × depth
      case 'TRAPEZOIDAL':
        return d * (geom1 + d * (geom1 || 0)); // approximate
      default:
        // Approximate as circular
        const D2 = geom1 || 1;
        const r2 = D2 / 2;
        const theta2 = 2 * Math.acos(Math.max(-1, Math.min(1, 1 - d / r2)));
        return r2 * r2 / 2 * (theta2 - Math.sin(theta2));
    }
  }

  getFullArea(shape, geom1, geom2) {
    switch (shape?.toUpperCase()) {
      case 'CIRCULAR': return Math.PI * geom1 * geom1 / 4;
      case 'RECT_CLOSED':
      case 'RECT_OPEN': return geom1 * (geom2 || geom1);
      default: return Math.PI * geom1 * geom1 / 4;
    }
  }

  getTopWidth(shape, geom1, depth) {
    const d = Math.max(0, Math.min(depth, geom1));
    switch (shape?.toUpperCase()) {
      case 'CIRCULAR': {
        const r = geom1 / 2;
        return 2 * Math.sqrt(Math.max(0, r * r - (r - d) * (r - d)));
      }
      case 'RECT_CLOSED':
      case 'RECT_OPEN':
        return geom1 || d;
      default: {
        const r = geom1 / 2;
        return 2 * Math.sqrt(Math.max(0, r * r - (r - d) * (r - d)));
      }
    }
  }

  getHydRadius(shape, geom1, depth) {
    const area = this.getArea(shape, geom1, depth);
    // Approximate wetted perimeter
    const d = Math.max(0.001, Math.min(depth, geom1));
    switch (shape?.toUpperCase()) {
      case 'CIRCULAR': {
        const r = geom1 / 2;
        const theta = 2 * Math.acos(Math.max(-1, Math.min(1, 1 - d / r)));
        const P = r * theta;
        return P > 0 ? area / P : 0;
      }
      default: {
        const r = geom1 / 2;
        const theta = 2 * Math.acos(Math.max(-1, Math.min(1, 1 - d / r)));
        const P = r * theta;
        return P > 0 ? area / P : 0;
      }
    }
  }

  getFullHydRadius(shape, geom1, geom2) {
    switch (shape?.toUpperCase()) {
      case 'CIRCULAR': return geom1 / 4;
      case 'RECT_CLOSED': return (geom1 * (geom2 || geom1)) / (2 * geom1 + 2 * (geom2 || geom1));
      default: return geom1 / 4;
    }
  }
}
```
