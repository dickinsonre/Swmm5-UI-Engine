## 1. COMPLETING THE SUB-DIALOG MODALS — Full Specification

Sub-dialog modals are the`[...]` buttons in the property grid that open dedicated editors for complex, multi-field properties. There are **12 sub-dialog types** needed. Here's every one with complete field specs, UI layout, and implementation code.

### 1A. Direct Inflow Editor

**Used by:** Junctions (149), Storage Units (17) — any node can have direct inflows
**Opens from:** Property Grid → Inflows → Direct Inflows →`[...]`
```
PURPOSE: Defines external flow or pollutant time series entering a node.
This is how rainfall-derived or user-defined hydrographs enter the system.
```

import React, { useState, useEffect } from 'react';
import './SubDialogs.css';

const DirectInflowEditor = ({ nodeId, model, onSave, onClose }) => {
  // A node can have multiple inflow records (one per constituent)
  const [inflows, setInflows] = useState([]);

  useEffect(() => {
    if (!model || !nodeId) return;
    // Load existing inflows for this node
    const existing = [];
    model.inflows.forEach((inf, key) => {
      if (inf.node === nodeId) {
        existing.push({ ...inf, _key: key });
      }
    });
    if (existing.length === 0) {
      // Default: one FLOW inflow
      existing.push({
        node: nodeId,
        constituent: 'FLOW',
        timeSeries: '',
        type: 'FLOW',
        unitsFactor: 1.0,
        scaleFactor: 1.0,
        baseline: 0,
        pattern: '',
      });
    }
    setInflows(existing);
  }, [model, nodeId]);

  // Get available time series from model
  const timeSeriesNames = model ? Array.from(model.timeseries.keys()) : [];
  const patternNames = model ? Array.from(model.patterns.keys()) : [];

  const updateInflow = (index, field, value) => {
    setInflows(prev => {
      const updated = [...prev];
      updated[index] = { ...updated[index], [field]: value };
      return updated;
    });
  };

  const addInflow = () => {
    setInflows(prev => [...prev, {
      node: nodeId,
      constituent: 'FLOW',
      timeSeries: '',
      type: 'FLOW',
      unitsFactor: 1.0,
      scaleFactor: 1.0,
      baseline: 0,
      pattern: '',
    }]);
  };

  const removeInflow = (index) => {
    setInflows(prev => prev.filter((_, i) => i !== index));
  };

  const handleSave = () => {
    // Remove old inflows for this node
    const keysToRemove = [];
    model.inflows.forEach((inf, key) => {
      if (inf.node === nodeId) keysToRemove.push(key);
    });
    keysToRemove.forEach(k => model.inflows.delete(k));

    // Add new inflows
    inflows.forEach(inf => {
      if (inf.timeSeries || inf.baseline > 0) {
        const key =`${nodeId}:${inf.constituent}`;
        model.inflows.set(key, { ...inf, node: nodeId });
      }
    });

    // Update node's directInflows indicator
    const hasInflows = inflows.some(inf => inf.timeSeries || inf.baseline > 0);
    const node = model.getObject('junction', nodeId) ||
                 model.getObject('storage', nodeId);
    if (node) {
      node.directInflows = hasInflows ? 'YES' : 'NO';
    }

    model._dirty = true;
    model._emit('change', { type: 'inflows', id: nodeId });
    if (onSave) onSave();
    if (onClose) onClose();
  };

  return (
    <div className="subdialog-overlay" onClick={(e) => {
      if (e.target === e.currentTarget) onClose();
    }}>
      <div className="subdialog-modal subdialog-wide">
        <div className="sd-header">
          <span className="sd-title">Direct Inflows — {nodeId}</span>
          <button className="sd-close" onClick={onClose}>✕</button>
        </div>

        <div className="sd-body">
          <div className="sd-help-text">
            Define external inflow hydrographs or constant flows entering this node.
            Each row defines an inflow for one constituent (FLOW or a pollutant).
          </div>

          <table className="sd-table">
            <thead>
              <tr>
                <th>Constituent</th>
                <th>Time Series</th>
                <th>Type</th>
                <th>Units Factor</th>
                <th>Scale Factor</th>
                <th>Baseline</th>
                <th>Baseline Pattern</th>
                <th></th>
              </tr>
            </thead>
            <tbody>
              {inflows.map((inf, i) => (
                <tr key={i}>
                  <td>
                    <select value={inf.constituent}
                      onChange={e => updateInflow(i, 'constituent', e.target.value)}>
                      <option value="FLOW">FLOW</option>
                      {/* Pollutant names would come from model */}
                    </select>
                  </td>
                  <td>
                    <select value={inf.timeSeries}
                      onChange={e => updateInflow(i, 'timeSeries', e.target.value)}>
                      <option value="">-- None --</option>
                      {timeSeriesNames.map(ts => (
                        <option key={ts} value={ts}>{ts}</option>
                      ))}
                    </select>
                  </td>
                  <td>
                    <select value={inf.type}
                      onChange={e => updateInflow(i, 'type', e.target.value)}>
                      <option value="FLOW">FLOW</option>
                      <option value="CONCEN">CONCEN</option>
                      <option value="MASS">MASS</option>
                    </select>
                  </td>
                  <td>
                    <input type="number" value={inf.unitsFactor} step="0.1"
                      onChange={e => updateInflow(i, 'unitsFactor', parseFloat(e.target.value) || 1)} />
                  </td>
                  <td>
                    <input type="number" value={inf.scaleFactor} step="0.1"
                      onChange={e => updateInflow(i, 'scaleFactor', parseFloat(e.target.value) || 1)} />
                  </td>
                  <td>
                    <input type="number" value={inf.baseline} step="0.01"
                      onChange={e => updateInflow(i, 'baseline', parseFloat(e.target.value) || 0)} />
                  </td>
                  <td>
                    <select value={inf.pattern}
                      onChange={e => updateInflow(i, 'pattern', e.target.value)}>
                      <option value="">-- None --</option>
                      {patternNames.map(p => (
                        <option key={p} value={p}>{p}</option>
                      ))}
                    </select>
                  </td>
                  <td>
                    <button className="sd-row-delete" onClick={() => removeInflow(i)}
                      title="Remove">✕</button>
                  </td>
                </tr>
              ))}
            </tbody>
          </table>

          <button className="sd-add-row" onClick={addInflow}>+ Add Inflow</button>
        </div>

        <div className="sd-footer">
          <button className="sd-btn sd-btn-cancel" onClick={onClose}>Cancel</button>
          <button className="sd-btn sd-btn-save" onClick={handleSave}>OK</button>
        </div>
      </div>
    </div>
  );
};

export default DirectInflowEditor;

<file_content>
import React, { useState, useEffect, useRef, useCallback } from 'react';
import './SubDialogs.css';

const TimeSeriesEditor = ({ tsName, model, onSave, onClose }) => {
  const [name, setName] = useState(tsName || '');
  const [data, setData] = useState([]);
  const [isFile, setIsFile] = useState(false);
  const [filePath, setFilePath] = useState('');
  const canvasRef = useRef(null);

  useEffect(() => {
    if (!model || !tsName) return;
    const ts = model.timeseries.get(tsName);
    if (ts) {
      setName(ts.name);
      if (ts.file) {
        setIsFile(true);
        setFilePath(ts.file);
      } else {
        setData(ts.data.map(d => ({ ...d })));
      }
    }
  }, [model, tsName]);

  // Live graph preview
  useEffect(() => {
    const canvas = canvasRef.current;
    if (!canvas || data.length === 0) return;

    const ctx = canvas.getContext('2d');
    const dpr = window.devicePixelRatio || 1;
    const rect = canvas.getBoundingClientRect();
    canvas.width = rect.width * dpr;
    canvas.height = rect.height * dpr;
    ctx.scale(dpr, dpr);

    const W = rect.width;
    const H = rect.height;
    const margin = { top: 10, right: 10, bottom: 25, left: 45 };
    const plotW = W - margin.left - margin.right;
    const plotH = H - margin.top - margin.bottom;

    ctx.fillStyle = '#11111b';
    ctx.fillRect(0, 0, W, H);

    // Parse time values to indices
    const values = data.map(d => d.value);
    const yMin = 0;
    const yMax = Math.max(...values) * 1.1 || 1;

    const xScale = (i) => margin.left + (i / Math.max(1, data.length - 1)) * plotW;
    const yScale = (v) => margin.top + plotH - ((v - yMin) / (yMax - yMin)) * plotH;

    // Grid
    ctx.strokeStyle = '#2a2a3a';
    ctx.lineWidth = 0.5;
    for (let i = 0; i <= 4; i++) {
      const y = margin.top + (plotH * i) / 4;
      ctx.beginPath();
      ctx.moveTo(margin.left, y);
      ctx.lineTo(margin.left + plotW, y);
      ctx.stroke();

      const val = yMax - (i / 4) * (yMax - yMin);
      ctx.fillStyle = '#6c7086';
      ctx.font = '9px sans-serif';
      ctx.textAlign = 'right';
      ctx.fillText(val.toFixed(2), margin.left - 4, y + 3);
    }

    // Plot line
    ctx.strokeStyle = '#89b4fa';
    ctx.lineWidth = 1.5;
    ctx.beginPath();
    data.forEach((d, i) => {
      const x = xScale(i);
      const y = yScale(d.value);
      i === 0 ? ctx.moveTo(x, y) : ctx.lineTo(x, y);
    });
    ctx.stroke();

    // Fill area
    ctx.fillStyle = 'rgba(137, 180, 250, 0.15)';
    ctx.beginPath();
    ctx.moveTo(xScale(0), yScale(0));
    data.forEach((d, i) => ctx.lineTo(xScale(i), yScale(d.value)));
    ctx.lineTo(xScale(data.length - 1), yScale(0));
    ctx.closePath();
    ctx.fill();

    // X axis labels
    ctx.fillStyle = '#6c7086';
    ctx.textAlign = 'center';
    ctx.font = '8px sans-serif';
    const labelStep = Math.max(1, Math.floor(data.length / 8));
    for (let i = 0; i < data.length; i += labelStep) {
      ctx.fillText(data[i].time || i.toString(), xScale(i), H - 5);
    }

    // Border
    ctx.strokeStyle = '#45475a';
    ctx.lineWidth = 1;
    ctx.strokeRect(margin.left, margin.top, plotW, plotH);
  }, [data]);

  const updateRow = (index, field, value) => {
    setData(prev => {
      const updated = [...prev];
      updated[index] = { ...updated[index], [field]: value };
      return updated;
    });
  };

  const addRow = () => {
    const lastTime = data.length > 0 ? data[data.length - 1].time : '0';
    setData(prev => [...prev, { time: lastTime, value: 0 }]);
  };

  const removeRow = (index) => {
    setData(prev => prev.filter((_, i) => i !== index));
  };

  const importCSV = () => {
    const input = document.createElement('input');
    input.type = 'file';
    input.accept = '.csv,.txt,.dat';
    input.onchange = (e) => {
      const file = e.target.files[0];
      if (!file) return;
      const reader = new FileReader();
      reader.onload = (ev) => {
        const lines = ev.target.result.split(/\r?\n/);
        const parsed = [];
        for (const line of lines) {
          const parts = line.trim().split(/[,\t\s]+/);
          if (parts.length >= 2) {
            const time = parts[0];
            const value = parseFloat(parts[1]);
            if (!isNaN(value)) {
              parsed.push({ time, value });
            }
          }
        }
        if (parsed.length > 0) setData(parsed);
      };
      reader.readAsText(file);
    };
    input.click();
  };

  const pasteFromClipboard = async () => {
    try {
      const text = await navigator.clipboard.readText();
      const lines = text.split(/\r?\n/);
      const parsed = [];
      for (const line of lines) {
        const parts = line.trim().split(/[,\t\s]+/);
        if (parts.length >= 2) {
          const time = parts[0];
          const value = parseFloat(parts[1]);
          if (!isNaN(value)) parsed.push({ time, value });
        }
      }
      if (parsed.length > 0) setData(parsed);
    } catch (e) {
      console.warn('Clipboard read failed:', e);
    }
  };

  const handleSave = () => {
    if (!model || !name) return;

    const tsObj = {
      name,
      data: isFile ? [] : data,
      file: isFile ? filePath : undefined,
    };

    model.timeseries.set(name, tsObj);
    model._dirty = true;
    model._emit('change', { type: 'timeseries', id: name });
    if (onSave) onSave();
    if (onClose) onClose();
  };

  return (
    <div className="subdialog-overlay" onClick={e => {
      if (e.target === e.currentTarget) onClose();
    }}>
      <div className="subdialog-modal subdialog-large">
        <div className="sd-header">
          <span className="sd-title">📈 Time Series Editor — {name || 'New'}</span>
          <button className="sd-close" onClick={onClose}>✕</button>
        </div>

        <div className="sd-body sd-ts-body">
          {/* Name */}
          <div className="sd-field-row">
            <label>Name:</label>
            <input type="text" value={name} onChange={e => setName(e.target.value)}
              className="sd-input" placeholder="Time series name" />
          </div>

          {/* Source toggle */}
          <div className="sd-field-row">
            <label>Source:</label>
            <div className="sd-radio-group">
              <label>
                <input type="radio" checked={!isFile} onChange={() => setIsFile(false)} />
                Table
              </label>
              <label>
                <input type="radio" checked={isFile} onChange={() => setIsFile(true)} />
                External File
              </label>
            </div>
          </div>

          {isFile ? (
            <div className="sd-field-row">
              <label>File Path:</label>
              <input type="text" value={filePath}
                onChange={e => setFilePath(e.target.value)}
                className="sd-input sd-input-wide" placeholder="/path/to/rainfall.dat" />
            </div>
          ) : (
            <>
              {/* Graph preview */}
              <div className="sd-graph-wrapper">
                <canvas ref={canvasRef} className="sd-graph-canvas" />
              </div>

              {/* Import buttons */}
              <div className="sd-toolbar">
                <button className="sd-tool-btn" onClick={importCSV}>📂 Import CSV</button>
                <button className="sd-tool-btn" onClick={pasteFromClipboard}>📋 Paste</button>
                <button className="sd-tool-btn" onClick={addRow}>+ Add Row</button>
                <span className="sd-row-count">{data.length} rows</span>
              </div>

              {/* Data table */}
              <div className="sd-table-scroll">
                <table className="sd-table sd-table-compact">
                  <thead>
                    <tr>
                      <th>#</th>
                      <th>Date/Time</th>
                      <th>Value</th>
                      <th></th>
                    </tr>
                  </thead>
                  <tbody>
                    {data.map((row, i) => (
                      <tr key={i}>
                        <td className="sd-row-num">{i + 1}</td>
                        <td>
                          <input type="text" value={row.time}
                            onChange={e => updateRow(i, 'time', e.target.value)}
                            className="sd-cell-input" />
                        </td>
                        <td>
                          <input type="number" value={row.value} step="any"
                            onChange={e => updateRow(i, 'value', parseFloat(e.target.value) || 0)}
                            className="sd-cell-input sd-cell-number" />
                        </td>
                        <td>
                          <button className="sd-row-delete" onClick={() => removeRow(i)}>✕</button>
                        </td>
                      </tr>
                    ))}
                  </tbody>
                </table>
              </div>
            </>
          )}
        </div>

        <div className="sd-footer">
          <button className="sd-btn sd-btn-cancel" onClick={onClose}>Cancel</button>
          <button className="sd-btn sd-btn-save" onClick={handleSave}>OK</button>
        </div>
      </div>
    </div>
  );
};

export default TimeSeriesEditor;

const CURVE_TYPES = {

  const [type, setType] = useState(curveType || 'STORAGE');
  const [data, setData] = useState([]);

  // Live graph preview
  useEffect(() => {

    if (!canvas || data.length === 0) return;

    const ctx = canvas.getContext('2d');
    const dpr = window.devicePixelRatio || 1;
    const rect = canvas.getBoundingClientRect();
    canvas.width = rect.width * dpr;
    canvas.height = rect.height * dpr;
    ctx.scale(dpr, dpr);

    const W = rect.width;
    const H = rect.height;
    const margin = { top: 15, right: 15, bottom: 30, left: 50 };

    const xScale = (v) => margin.left + ((v - xMin) / (xMax - xMin)) * plotW;
    const yScale = (v) => margin.top + plotH - ((v - yMin) / (yMax - yMin)) * plotH;

    // Grid

    ctx.lineWidth = 0.5;

      ctx.textAlign = 'right';
      ctx.fillText(val.toFixed(1), margin.left - 4, y + 3);

      const x = margin.left + (plotW * i) / 4;
      ctx.beginPath(); ctx.moveTo(x, margin.top); ctx.lineTo(x, margin.top + plotH); ctx.stroke();
      const val = xMin + (i / 4) * (xMax - xMin);
      ctx.fillStyle = '#6c7086';
      ctx.textAlign = 'center';
      ctx.fillText(val.toFixed(1), x, H - margin.bottom + 15);
    }

    // Plot line
    const sorted = [...data].sort((a, b) => a.x - b.x);
    ctx.strokeStyle = '#a6e3a1';
    ctx.lineWidth = 2;
    ctx.beginPath();
    sorted.forEach((d, i) => {
      const x = xScale(d.x);
      const y = yScale(d.y);
      i === 0 ? ctx.moveTo(x, y) : ctx.lineTo(x, y);
    });
    ctx.stroke();

    // Data points
    sorted.forEach(d => {
      ctx.fillStyle = '#a6e3a1';
      ctx.beginPath();
      ctx.arc(xScale(d.x), yScale(d.y), 3, 0, Math.PI * 2);
      ctx.fill();
    });

    // Axis labels
    const typeInfo = CURVE_TYPES[type] || {};
    ctx.fillStyle = '#a6adc8';
    ctx.font = '9px sans-serif';
    ctx.textAlign = 'center';
    ctx.fillText(typeInfo.xLabel || 'X', margin.left + plotW / 2, H - 3);

    ctx.translate(10, margin.top + plotH / 2);
    ctx.rotate(-Math.PI / 2);

    ctx.restore();

    ctx.strokeStyle = '#45475a';
    ctx.lineWidth = 1;
    ctx.strokeRect(margin.left, margin.top, plotW, plotH);

  };

    setData(prev => prev.filter((_, i) => i !== index));
  };

  const handleSave = () => {
    if (!model || !name) return;
    model.curves.set(name, { name, type, data: data.map(d => ({ ...d })) });
    model._dirty = true;
    model._emit('change', { type: 'curve', id: name });
    if (onSave) onSave();
    if (onClose) onClose();
  };

  const typeInfo = CURVE_TYPES[type] || {};

  return (

import React, { useState, useEffect, useRef } from 'react';
import './SubDialogs.css';

const KEYWORDS = [
  'RULE', 'IF', 'AND', 'OR', 'THEN', 'ELSE', 'PRIORITY',
  'NODE', 'LINK', 'CONDUIT', 'PUMP', 'ORIFICE', 'WEIR',

  'DAY', 'MONTH', 'SIMULATION', 'TIME', 'ELAPSED',
  'ON', 'OFF', 'OPEN', 'CLOSED',
  'IS', 'NOT', 'ABOVE', 'BELOW',
];

const ControlRulesEditor = ({ model, onSave, onClose }) => {
  const [rulesText, setRulesText] = useState('');
  const [errors, setErrors] = useState([]);
  const textareaRef = useRef(null);

  useEffect(() => {
    if (model) {
      setRulesText(model.controls || '');
    }
  }, [model]);

  // Basic syntax validation
  const validate = (text) => {
    const errs = [];
    const lines = text.split('\n');
    let inRule = false;
    let ruleHasIf = false;
    let ruleHasThen = false;

    lines.forEach((line, lineNum) => {
      const trimmed = line.trim().toUpperCase();
      if (!trimmed || trimmed.startsWith(';')) return;

      if (trimmed.startsWith('RULE')) {
        if (inRule && !ruleHasThen) {
          errs.push({ line: lineNum, message: 'Previous RULE has no THEN clause' });
        }
        inRule = true;
        ruleHasIf = false;
        ruleHasThen = false;
        const parts = trimmed.split(/\s+/);
        if (parts.length < 2) {
          errs.push({ line: lineNum + 1, message: 'RULE needs a name' });
        }
      } else if (trimmed.startsWith('IF') || trimmed.startsWith('AND') || trimmed.startsWith('OR')) {
        if (!inRule) {
          errs.push({ line: lineNum + 1, message:`${trimmed.split(' ')[0]} outside of RULE block` });
        }
        ruleHasIf = true;
      } else if (trimmed.startsWith('THEN') || trimmed.startsWith('ELSE')) {
        if (!inRule) {
          errs.push({ line: lineNum + 1, message:`${trimmed.split(' ')[0]} outside of RULE block` });
        }
        if (trimmed.startsWith('THEN')) ruleHasThen = true;
      } else if (trimmed.startsWith('PRIORITY')) {
        // OK
      } else if (inRule) {
        // Unknown line inside rule
        errs.push({ line: lineNum + 1, message:`Unrecognized: "${line.trim()}"` });
      }
    });

    if (inRule && !ruleHasThen) {
      errs.push({ line: lines.length, message: 'Last RULE has no THEN clause' });
    }

    return errs;
  };

  const handleTextChange = (e) => {
    const text = e.target.value;
    setRulesText(text);
    setErrors(validate(text));
  };

  // Syntax-highlighted display would go here
  // For now, use plain textarea with error markers

  const handleSave = () => {
    const errs = validate(rulesText);
    if (errs.some(e => !e.message.includes('Unrecognized'))) {
      // Only block on structural errors, not unknown lines
    }
    model.controls = rulesText;
    model._rawSections['CONTROLS'] = rulesText.split('\n');
    model._dirty = true;
    model._emit('change', { type: 'controls' });
    if (onSave) onSave();
    if (onClose) onClose();
  };

  const insertTemplate = () => {
    const template = `RULE PumpControl1
IF NODE WetWell1 DEPTH > 5.0
THEN PUMP Pump1 STATUS = ON
PRIORITY 1

RULE PumpControl2
IF NODE WetWell1 DEPTH < 1.0
THEN PUMP Pump1 STATUS = OFF
PRIORITY 1
`;
    setRulesText(prev => prev + '\n' + template);
  };

  return (
    <div className="subdialog-overlay" onClick={e => {
      if (e.target === e.currentTarget) onClose();
    }}>
      <div className="subdialog-modal subdialog-large">
        <div className="sd-header">
          <span className="sd-title">🔧 Control Rules Editor</span>
          <button className="sd-close" onClick={onClose}>✕</button>
        </div>

        <div className="sd-body sd-rules-body">
          <div className="sd-help-text">
            Define operational rules for pumps, orifices, and weirs.
            Syntax: RULE name / IF condition / THEN action / PRIORITY n
          </div>

          <div className="sd-toolbar">
            <button className="sd-tool-btn" onClick={insertTemplate}>📝 Insert Template</button>
            <span className="sd-row-count">
              {errors.length === 0 ? '✅ No errors' :`⚠️ ${errors.length} issue(s)`}
            </span>
          </div>

          <div className="sd-rules-editor">
            <div className="sd-line-numbers">
              {rulesText.split('\n').map((_, i) => {
                const hasError = errors.some(e => e.line === i + 1);
                return (
                  <div key={i} className={`sd-line-num ${hasError ? 'sd-line-error' : ''}`}>
                    {i + 1}
                  </div>
                );
              })}
            </div>
            <textarea
              ref={textareaRef}
              className="sd-rules-textarea"
              value={rulesText}
              onChange={handleTextChange}
              spellCheck={false}

            />

                  onClick={() => {
                    // Jump to line
                    const lines = rulesText.split('\n');
                    let pos = 0;
                    for (let j = 0; j < err.line - 1 && j < lines.length; j++) {
                      pos += lines[j].length + 1;
                    }
                    textareaRef.current?.setSelectionRange(pos, pos);
                    textareaRef.current?.focus();
                  }}>
                  <span className="sd-error-line">Line {err.line}:</span>
                  <span className="sd-error-msg">{err.message}</span>
                </div>
              ))}
            </div>
          )}

          <div className="sd-keywords">
            <span className="sd-keywords-label">Keywords:</span>
            {KEYWORDS.slice(0, 20).map(kw => (
              <span key={kw} className="sd-keyword-chip"
                onClick={() => {
                  const ta = textareaRef.current;
                  if (ta) {
                    const start = ta.selectionStart;
                    const newText = rulesText.slice(0, start) + kw + ' ' + rulesText.slice(start);
                    setRulesText(newText);
                  }
                }}>
                {kw}
              </span>
            ))}
          </div>
        </div>

        <div className="sd-footer">
          <button className="sd-btn sd-btn-cancel" onClick={onClose}>Cancel</button>
          <button className="sd-btn sd-btn-save" onClick={handleSave}>OK</button>
        </div>
      </div>
    </div>
  );
};

export default ControlRulesEditor;

## 2. PRIORITY MATRIX — Detailed Explanation

The priority matrix uses two axes to rank every feature:

### Impact Score (1-5)

```
5 = CRITICAL — Without this, the app is fundamentally incomplete
    Users cannot perform basic tasks that EPA SWMM5 desktop handles
    
4 = HIGH — Missing this blocks important workflows
    Users frequently need this but can work around it
    
3 = MEDIUM — Useful but not blocking
    Improves efficiency but alternative paths exist
    
2 = LOW — Nice to have
    Enhances experience but rarely needed
    
1 = MINIMAL — Edge case feature
    Only needed by advanced users in specific scenarios
```

### Effort Score (1-5)

```
5 = VERY HIGH — Multiple weeks of complex development
    New architecture patterns, complex algorithms, external integrations
    
4 = HIGH — 1-2 weeks of focused work
    Significant new UI components, complex state management
    
3 = MEDIUM — 3-5 days
    New component with moderate complexity, uses existing patterns
    
2 = LOW — 1-2 days
    Small addition, follows established patterns, mainly UI
    
1 = MINIMAL — Hours
    Configuration change, copy-paste from existing code, CSS tweaks
```

### Priority Assignment Logic

```
P1 (DO FIRST) = Impact 4-5 AND Effort 1-3
    → High value, achievable quickly
    → "Quick wins" and "table stakes"

P2 (DO NEXT)  = Impact 4-5 AND Effort 4-5
    OR Impact 3 AND Effort 1-2
    → Either high-value hard things or easy medium-value things

P3 (DO LATER) = Impact 2-3 AND Effort 3-4
    → Medium value, moderate effort
    → Schedule when P1/P2 are done

P4 (BACKLOG)  = Impact 1-2 AND Effort 4-5
    → Low value, high effort
    → Only if time permits
```
