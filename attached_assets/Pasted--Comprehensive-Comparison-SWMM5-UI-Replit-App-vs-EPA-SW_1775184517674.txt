# Comprehensive Comparison: SWMM5-UI (Replit App) vs. EPA SWMM5 Desktop GUI

## Overview

The Replit app at **swmm-ui-engine.replit.app** is a web-based reimplementation of the EPA SWMM5 desktop application. Based on the visible interface elements and the original EPA SWMM5 GUI (written in Delphi/Pascal), here is a detailed gap analysis and improvement roadmap.

---

## 2. WHAT'S MISSING — DETAILED COMPARISON 🔴

### 2.1 FILE MENU FEATURES

**EPA SWMM5 has:**
- **New Project** — create blank project from scratch
- **Open** — file browser dialog for .inp files
- **Reopen** — recently opened files list (MRU)
- **Save / Save As** — export modified .inp back to disk
- **Export** — export to various formats (hotstart files, map coordinates, report files)
- **Page Setup / Print Preview / Print** — printing the map/reports
- **Preferences** — global application settings (fonts, colors, units, number formats, auto-backup, confirmations)

**What's likely missing:**
```
🔴 Save / Save As to download modified .inp
🔴 Recent files list (MRU)
🔴 Export to hotstart (.hsf) file
🔴 Export map coordinates
🔴 Print / Page Setup / Print Preview
🔴 Preferences dialog (fonts, number formats, auto-backup, confirmations)
🔴 New blank project creation wizard
```

### 2.2 EDIT MENU FEATURES

**EPA SWMM5 has:**
- **Copy to Clipboard** (map, tables)
- **Select Object / Select Region / Select All**
- **Group Edit** — bulk-edit properties of selected objects
- **Group Delete**
- **Find Object** — search by ID
- **Design Queries** — highlight objects matching criteria (e.g., "all pipes with diameter > 24 inches")
- **Add/Delete objects interactively on map**

**What's likely missing:**
```
🔴 Copy to clipboard (map image, tabular data)
🔴 Find Object dialog (search by ID/name)
🔴 Design Queries (conditional highlighting/filtering)
🔴 Full Group Edit dialog (bulk property modification)
🔴 Undo/Redo functionality
```

### 2.4 PROJECT MENU FEATURES

**EPA SWMM5 has:**

**What's likely missing or incomplete:**


### 2.5 PROPERTY EDITOR (THE BIG ONE)

This is the **core interaction model** of EPA SWMM5 — clicking any object on the map or in the browser opens a property editor panel.

**EPA SWMM5 Property Editor supports ALL of these object types with full field editing:**

```
🔴 Subcatchment properties:
    - Name, Rain Gage, Outlet, Area, Width, % Slope
    - % Imperv, N-Imperv, N-Perv, Dstore-Imperv, Dstore-Perv
    - %Zero-Imperv, Subarea Routing, % Routed
    - Infiltration parameters (varies by method: Horton/Green-Ampt/Curve Number/Modified Horton/Modified Green-Ampt)
    - Groundwater parameters (aquifer, receiving node, coefficients)
    - Snow Pack assignment
    - LID Controls (multiple LID units per subcatchment)
    - Land Uses (for water quality)
    - Initial Buildup
    - Curb Length

🔴 Junction properties:
    - Name, Invert Elevation, Max Depth, Init Depth
    - Surcharge Depth, Ponded Area
    - External Inflows (Direct, Dry Weather, RDII)
    - Treatment expressions

🔴 Outfall properties:
    - Type (Free, Normal, Fixed, Tidal, Time Series)
    - Stage data, Tide gate, Route To subcatchment

🔴 Storage Unit properties:
    - Shape (Functional/Tabular), storage curve parameters
    - Evaporation factor, Seepage parameters
    - External inflows

🔴 Divider properties:
    - Type (Cutoff, Tabular, Weir, Overflow)
    - Divider parameters

🔴 Conduit properties:
    - Cross-section (20+ shapes: circular, rect-open, rect-closed,
      trapezoidal, triangular, horiz-ellipse, vert-ellipse, arch,
      parabolic, power, rect-triangular, rect-round, mod-baskethandle,
      egg, horseshoe, gothic, catenary, semi-elliptical, baskethandle,
      semi-circular, irregular/transect, custom, street)
    - Length, Roughness (Manning's n), Inlet/Outlet offsets
    - Initial flow, Max flow
    - Entry/Exit loss coefficients, Flap gate, Seepage

🔴 Pump properties:
    - Pump curve (Type 1-4, Ideal), Status, Startup/Shutoff depth

🔴 Orifice properties:
    - Type (Side/Bottom), Shape, Height, Width, Discharge Coeff
    - Flap gate, Time to open/close

🔴 Weir properties:
    - Type (Transverse, Side, V-Notch, Trapezoidal, Roadway)
    - Height, Length, Side slopes, Discharge coefficients
    - End contractions, Flap gate, Surcharge option

🔴 Outlet properties:
    - Type (Functional/Tabular), Rating curve, Flap gate

🔴 Rain Gage properties:
    - Format (Intensity/Volume/Cumulative), Interval
    - Data source (Time Series / File), File parameters
    - Snow catch factor, Station ID

🔴 All editors should support:
    - Inline editing in a property grid
    - Sub-dialogs for complex properties (curves, time series, etc.)
    - Validation and error messages
```

## 4. SPECIFIC TECHNICAL RECOMMENDATIONS FOR REPLIT

### 4.1 Property Editor Architecture
```javascript
// Recommend: A reusable PropertyGrid component
// EPA SWMM uses a two-column grid (Property Name | Value)
// with sub-dialogs for complex fields

<PropertyGrid
  object={selectedNode}
  schema={junctionSchema}
  onChange={(field, value) => updateModel(field, value)}
  onSubDialog={(field) => openEditor(field)}
/>

// Each object type needs a schema defining:
// - field name, type (string, number, enum, curve-ref, timeseries-ref)
// - validation rules (min, max, required)
// - sub-dialog triggers (e.g., "Inflows" opens inflow editor)
```

### 4.3 Cross-Section Renderer
```javascript
// EPA SWMM supports 20+ cross-section shapes
// Need a canvas/SVG renderer for the profile plot and conduit editor
// that can draw: circular, rectangular, egg, horseshoe, arch,
// irregular (from transect), etc.

function renderCrossSection(shape, params, ctx, x, y, scale) {
  switch(shape) {
    case 'CIRCULAR': drawCircle(ctx, params.diameter, x, y, scale); break;
    case 'RECT_CLOSED': drawRect(ctx, params.height, params.width, x, y, scale); break;
    case 'EGG': drawEgg(ctx, params.diameter, x, y, scale); break;
    // ... all shapes
  }
}
```

### 4.4 .inp Round-Trip Fidelity
```
CRITICAL: The parser must preserve:
- Comment lines (starting with ;)
- Blank lines and section ordering
- Precision of floating-point values
- Sections that the UI doesn't edit yet (pass-through)
- Tag formatting and ordering

This ensures: Load .inp → Edit → Save .inp produces
minimal diffs for version control.
```

### 4.5 Leverage Web Advantages Over Desktop
```
The desktop EPA SWMM5 GUI was written in Delphi in the early 2000s.
The web version can SURPASS it by:

1. 🗺️ Real map tiles (OpenStreetMap, satellite) as backdrop
   - Desktop SWMM requires manually loading a static image
   - Web app can use Leaflet/Mapbox with auto-georeferencing

2. 📊 Interactive charts (Plotly/D3) instead of static Win32 charts
   - Hover tooltips, zoom, pan on graphs
   - Export to interactive HTML

3. 🔗 Shareable URLs for specific model states
   - "Share this model" link

4. 🔄 Auto-save and browser storage
   - Never lose work

5. 📱 Works on any OS (Mac, Linux, Chromebook, tablet)
   - Desktop SWMM is Windows-only

6. 🤖 Integration with Python/R analytics
   - Run post-processing scripts server-side
   - pyswmm / swmmtoolbox integration
```

The app has an excellent foundation — the map rendering, project tree, and local engine integration are impressive for a web app. The biggest gaps are in **interactive editing** (property grids, sub-dialog editors) and **results post-processing** (animation, graphs, profile plots). Closing those two areas would bring it from ~40% to ~75% feature parity, which would make it genuinely useful for real engineering work.
