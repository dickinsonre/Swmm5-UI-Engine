# SWMM5-UI Replit App vs. EPA SWMM5 Desktop GUI: Complete Gap Analysis & Improvement Plan

## Current State Assessment

Based on the live app at **swmm-ui-engine.replit.app**, here's what exists and what's missing compared to the EPA SWMM5 desktop application (originally built in Delphi/Object Pascal).

---

## WHAT'S ALREADY WORKING ✅

| Feature | Details |
|---|---|
| **Project Explorer tree** | Title/Notes, Options, Climatology, Subcatchments(30), Junctions(149), Outfalls(5), Dividers(1), Storage(17), Conduits(223), Pumps(5), Orifices(2), Weirs(4), Outlets(1), Cross-Sections(229), Losses(223), DWF, Inflows, WQ, Controls, Map/GIS, Tags/Profiles |

### 🔴 PRIORITY 1: INTERACTIVE PROPERTY EDITING (The #1 Gap)

**This is the single biggest missing feature.** In EPA SWMM5, clicking ANY object opens a property editor panel. Without this, the app is a **viewer**, not an **editor**.

EPA SWMM5 uses a docked two-column property grid (Name | Value). The Replit app needs:

```

#### 3A. Basemap Tile Layers (Major Web Advantage!)

EPA SWMM5 desktop only supports manually loaded static backdrop images. The web app can **surpass** it:

```
IMPLEMENTATION with Leaflet.js:

Layer Control:
  ○ OpenStreetMap
  ○ Satellite (Esri World Imagery)  
  ○ Topo Map
  ○ Dark Mode (CartoDB Dark Matter)
  ○ None (current blank)
  
  Opacity: [████████░░] 80%

COORDINATE ALIGNMENT:
SWMM models use various coordinate systems:
  a) State Plane / UTM (large numbers like 2345678.0)
  b) Lat/Lon (decimal degrees like 35.612, -77.394)
  c) Arbitrary local (small numbers 0-1000)

Need:
  - Auto-detect coordinate type from value ranges
  - proj4js library for State Plane → Lat/Lon conversion
  - EPSG code selector for known projections
  - Manual georeferencing (2+ control points) for arbitrary coords
  - Fallback: static image backdrop (EPA SWMM5 compatibility)

FOR THIS MODEL (Greenville_SI.inp):
  - The "Greenville" in the filename suggests Greenville, SC or NC
  - If coordinates are State Plane, likely NC SP (EPSG:2264) 
    or SC SP (EPSG:2273)
  - Use proj4js to transform → render over satellite tiles
