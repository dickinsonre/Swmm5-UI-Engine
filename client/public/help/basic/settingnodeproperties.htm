Setting Node/Link Properties

    

The junctions and outfall of our drainage system need to have invert elevations assigned to them. As we did with the subcatchments, select each junction individually into the Property Editor and set its Invert Elevation to the value shown in the table below. Note.

 

Node

Invert

J1

96

J2

90

J3

93

J4

88

Out1

85

 

Only one of the conduits in our example system has a non-default property value. This is conduit C4, the outlet pipe, whose diameter should be 1.5 ft. instead of 1 ft. To change its diameter, select conduit C4 into the Property Editor and set the Max. Depth value to 1.5.
